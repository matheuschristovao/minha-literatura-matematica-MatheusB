# Material de apoio

| Arquivo | Para que serve |
|---|---|
| [`colinha-python_calculo-numerico.pdf`](colinha-python_calculo-numerico.pdf) | Folha de consulta rápida (2 páginas) com as funções de Python mais usadas no curso |

A folha está organizada em blocos:

- **Básico:** `print`, `input`, `range`, `len`, listas...
- **`math`:** `sqrt`, `exp`, `log`, funções trigonométricas, `floor`/`ceil`, `isnan`...
- **NumPy, estruturas e álgebra linear:** `array`, `linspace`, `reshape`, `@`, `linalg.solve`, `linalg.norm`, `linalg.eig`...
- **NumPy, operações vetorizadas e estatística:** `mean`, `std`, `polyfit`, `polyval`, `diff`...
- **Matplotlib:** `plot`, `scatter`, `semilogy`, `axhline`, `savefig`...
- **Dicas úteis:** critério de parada com `abs()`, erro vetorial com `linalg.norm`, `lambda` para definir $f(x)$...
